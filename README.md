# Flexozy Root Final

Everything is at one project root.

Root runtime:
- index.js
- package.json

Web:
- app/

API:
- api/v1/

Deploy this entire folder as the Vercel project.
Web domain: flexozy.online
API domain: api.flexozy.online
API base: https://api.flexozy.online/api/v1

Set QUEST_PROVIDER_URL and QUEST_PROVIDER_KEY in Vercel Environment Variables for real provider data.
