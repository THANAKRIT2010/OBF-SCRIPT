          API นี้อ่าน QR ในสลิปเพื่อกันสลิปซ้ำ/อ่านยอดเงินแบบ best-effort เท่านั้น ไม่ได้เชื่อมกับธนาคารจริง จึงยืนยัน 100% ไม่ได้ว่ามีการโอนเงินเกิดขึ้นจริง เหมาะใช้เป็นด่านกรองเบื้องต้นเท่านั้น
        

        curl -X POST https://flexozy.xyz/api/slip-check \
  -H "X-API-Key: flx_xxxxxxxx" \
  -F "file=@slip.jpg"
        
ผลลัพธ์ที่ได้: qr_found, duplicate, amount (ถ้าอ่านได้), qr_raw
