Slip Check API

            
สมาชิกกดขอ API key จากหน้าเว็บได้เอง แต่ต้องรออนุมัติจากตรงนี้ก่อนถึงจะใช้งานได้จริง

            

              
              API นี้อ่าน QR Code ในสลิปเพื่อกันสลิปซ้ำ และอ่านยอดเงินได้ถ้า QR เป็นรูปแบบ EMVCo เท่านั้น — ไม่ได้เชื่อมต่อกับธนาคารจริง จึงยืนยัน 100% ไม่ได้ว่ามีการโอนเงินจริง เหมาะกับใช้เป็นด่านแรกกรองสลิปซ้ำ/ปลอมง่ายๆ เท่านั้น
            

            

              
วิธีเรียกใช้ (สำหรับคนที่ได้รับอนุมัติ):

              POST /api/slip-check
Header: X-API-Key: flx_xxxxxxxx
Body: multipart/form-data field "file" = รูปสลิป
